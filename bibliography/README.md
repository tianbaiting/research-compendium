## Adding a citation

1. Retrieve metadata from publisher, Crossref, INSPIRE, arXiv, or a journal archive.
2. Check author spelling, year, title, journal, volume, page/article ID, and DOI against the primary entry.
3. Preserve stable keys once used in a released document.
4. Record if the source only supports an *interpretation*, as opposed to a *measurement*.
5. Do not store paywalled PDFs, copyright-restricted scans, or collaboration-private material in the repository.

Prefer DOI links (stable) and arXiv links (when a public preprint exists). For older material without a DOI, provide an archival URL and never guess a DOI.
