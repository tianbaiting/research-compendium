\section{What may actually be inferred?}\label{sec:cf-inference}
Both $S(\bm r^*)$ and the relative wave function in \cref{eq:cf-kp} can be unknown. The observable may therefore contain a source--interaction degeneracy. A fit parameter describing a scattering amplitude is constrained only to the extent that competing source hypotheses, spin channels, residual correlations and instrumental response have been controlled.

\subsection{Evidence and model ledger}
For each data set record the particle pair, collision system and energy, kinematic cuts, pair-rest-frame definition, event mixing, track and PID cuts, Coulomb prescription, source ansatz, covariance treatment, and model validation. A quoted radius or scattering length without these choices is not an interchangeable observable.

\subsection{Planned calculations}
\begin{enumerate}
\item Validate the kernel using simple analytic limits for neutral distinguishable particles.
\item Generate controlled source families and forward-fold correlation functions.
\item Quantify two-track efficiency and momentum/PID confusion with embedded pairs.
\item Propagate source and detector uncertainties into interaction confidence intervals.
\end{enumerate}
